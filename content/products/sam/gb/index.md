## 产品简介

SAM-GB 系列蚌式（抓斗）采泥器是专为**表层沉积物调查**而设计的底质取样设备，适用于各种河流、湖泊、港口、海洋等不同水深条件下各种表层底质的取样工作，现已广泛用于**表层沉积物调查、工程地质调查、物探验证调查、矿物调查、生物及地球化学调查**等领域，效果非常理想，受到各用户单位的一致好评。

## 产品结构与特点

整机由以下五大核心部件/系统构成：

1. **316L 不锈钢主体与双瓣斗体**
   - 材质：316L 不锈钢，耐海水腐蚀、机械强度高
   - 结构：对称双瓣（蚌式）斗体结构，开口状态下放到底床，触发后斗体闭合形成封闭取样仓，实现沉积物原状封存

2. **闭合触发机构（双样式可选）**
   - 工作原理：下放到位后，通过触发机构释放双瓣斗体闭合抓取沉积物
   - 特点：结构简单、触发可靠、现场维护方便，可重复使用

3. **两种作业样式（C 系列链条式 vs L 系列杆式）**

   | 对比项 | 链条式（C 系列） | 杆式（L 系列） |
   |--------|-------------------|----------------|
   | 触发方式 | 绞车钢缆 + 链条配重触发 | 长杆 + 顶端释放器触发 |
   | 适用水深 | 深海、大深度作业（可配铅配重） | 浅海、湖泊、水库等便携取样 |
   | 结构特点 | 结构稳固，抗冲击能力强 | 自重轻，单人可便携操作 |
   | 现场维护 | 简单方便 | 更简单、零件更少 |

4. **铅配重系统（链条式 C 系列选配）**
   - 作用：增加下落动量，保证在较深水域和砂质底床中斗体有效切入
   - 规格：根据型号可选配不同等级铅块，耐腐蚀、长期稳定

5. **多规格覆盖、灵活选型**
   - 开口尺寸：250 / 500 / 1000 cm² 三档，覆盖 2L / 5L / 16.6L 三级采样量
   - 样式 × 规格：链条式 × 3 规格 + 杆式 × 3 规格，共计 6 款型号，满足不同调查规范与现场条件

## 适用场景

1. **表层沉积物常规普查**：近海、港湾、河口、湖泊、水库表层沉积物定量/定性常规采样
2. **工程地质勘察**：海上风电、港口航道、人工岛、跨海桥梁前期工程地质普查取样
3. **物探验证调查**：海底管线路由、地震剖面、声呐探测异常点的物探验证取样
4. **矿物与地球化学调查**：砂矿、重矿物、多金属结核调查及地球化学分析采样
5. **科研教学与监测站常规监测**：高校海洋/地质专业教学实验、监测站年度底质环境监测
6. **与箱式/柱状产品联动选型**：蚌式抓斗用于大面积快速普查 → 发现异常点位后用 SAM-BX 箱式采原状样/取上覆水 → 重点钻孔用 DDC-Z-3 振动活塞取深部柱状样，形成完整沉积物调查作业链
