## 产品简介

SAM-GPC-30 重力活塞取样器系统，主要用于**获取质量较高的长柱状沉积物岩芯样**，为海洋地质、海洋沉积、海洋环境监测、海洋资源调查研究提供设备保障。重力活塞取样器是深海海洋地质科学研究中现场底质沉积物取样工作的一种重要技术装备。

## 产品特点

SAM-GPC-30 重力活塞取样器具备以下五大核心性能：

1. **取样深度：30 m**
   - 采用 5 根 6m 取样管拼接组合，单根长度 6000mm，合计可一次性获取 30m 连续长柱状沉积物岩芯，适配深海长序列沉积层序研究需求

2. **样品直径为 100 mm**
   - 标准取样管内径 Φ100mm，钢管外径不小于 159mm、壁厚不小于 22mm，样品直径统一、横截面均匀，便于实验室分样与测试

3. **设备总长 33 m**
   - 配置全套标准出厂拼接后总长约 33m，配合平衡杆释放器、活塞、提头配重管、切割头整套系统，适配绝大多数海洋科考船 A 字架 / 绞车作业空间要求

4. **最大工作水深 6000 m**
   - 主体结构与活塞系统针对深海高压工况设计，可在全球绝大多数深海海域开展沉积物作业，是远洋深海科考项目必备装备

5. **设备总重量：4.5~5 吨（空气中）**
   - 整套系统（含配重铅锭 3 吨 + 机械结构部分）约 4.5~5 吨，结构件坚固耐冲击、可承受高下落冲力，可长期适应海洋环境下服役

## 设备组成

| 组成系统 | 核心配置说明 |
|----------|--------------|
| **释放触发系统** | 30m 重力活塞取样器系统具备**释放触发方式平衡杆释放装置，可配合平衡杆长度 1.5m、活塞 1 枚，适配 110 型样品管，重锤不小于 200 公斤 |
| **承重提管** | 承重头设计两个能够安装两个卸扣的吊孔和两个止荡孔；采用直通式设计，取样衬管可以直接通至承重头处，既可保证样品不会出现冒顶的现象，也可以为用户提供一种提取样衬管的方式 |
| **取样系统** | 取样系统由 5 根取样管及取样管接头构成；单根取样管的长度 6000mm，合计最大取样长度 30m |
| **双层密封刀口** | 结合德国「太阳鸿」上重力取样器的内刀口优势和我们组合刀口的优势，在刀口内设计两层密封装置，一层是**莲花瓣式密封花瓣**，一层是**活板**，适用于深海软泥沉积物取样 |
| **活塞系统** | 采用 2205 或 Q345B 优质合金钢，可提供 **0.5MPa 负压**，**承重能力 20 吨**，保证活塞与管内壁密封良好、取芯过程中维持负压抽吸效果 |
| **平衡杆释放器** | 平衡杆长度 1.5 米，活塞 1 枚，适用于 110 型样品管，重锤不小于 200 公斤 |

## 选型对比（两种材质可选）

| 参数类别 | SAM-GPC-30-SS（不锈钢款） | SAM-GPC-30-AS（合金钢款） |
|----------|-----------------------------|------------------------------|
| **主体材质** | 2205 不锈钢（双相不锈钢，耐海水腐蚀性能优异） | Q345B 低合金高强度结构钢（经济耐用型） |
| **取样管** | 单根长度不大于 6 米，取样管外径不小于 159mm，壁厚不小于 22mm，每台设备需 **5 根** | 同 SS 款相同外形尺寸规格，材质为 Q345B |
| **配置管** | 外径不小于 159mm，壁厚不小于 20mm，最大配重容量 5 吨，每台设备需 1 根 | 同 SS 款外形尺寸规格，材质为 Q345B |
| **配重** | 铅锭，每台设备需 3 吨 | 铅锭，每台设备需 3 吨 |
| **承重头** | 承重力 15 吨，每台设备需 1 套 | 承重力 15 吨，每台设备需 1 套 |
| **双层密封刀口** | 自闭式活板密封和弹簧花瓣结合使用，适合深海软泥沉积物取样 | 同 SS 款密封结构 |
| **平衡杆释放器** | 平衡杆长度 1.5 米，活塞 1 枚，适用于 110 型样品管，重锤不小于 200 公斤，每台设备需 1 套 | 同 SS 款结构规格 |

> 💡 **选型建议**：长期远洋 / 高湿高盐雾环境长期存放 → 推荐 SS 款（2205 不锈钢耐腐蚀更好）；预算控制、近岸或周期使用且注重性价比 → 推荐 AS 款（Q345B 合金结构钢）。

## 适用场景

1. **深海海洋地质与第四纪沉积学研究**：全球远洋深海海域 6000m 水深以内海底长柱状沉积物岩芯取样，开展层序地层、古气候古环境重建
2. **海洋环境监测**：国家/区域海洋污染监测基线调查，获取长柱样进行重金属、有机污染物等纵向分布研究
3. **海洋资源调查**：海底多金属结核、富钴结壳、砂矿等资源调查的沉积物采样
4. **高校海洋地质 / 海洋沉积学实验室**：教学实习科研院所（海洋一所、海洋二所、地调所相关高校海洋地质系）常规配备
5. **与 DDC-Z-3 / SAM-GC-9 柱状取样矩阵联动选型**：
   - 近海浅层 / 硬底质 / 砂质铁板砂场景 → DDC-Z-3（振动活塞，0.5~3m+）
   - 浅海 / 泥质 / 经济型 9m 长柱场景 → SAM-GC-9（纯重力柱，9m）
   - 深海 6000m 水深 / 科研级 30m 保真正交长柱场景 → SAM-GPC-30（本条，重力活塞+负压）
