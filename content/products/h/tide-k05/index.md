## 产品简介

H-TIDE-K05 型潮位仪是一体化高精度水压与水温长期监测设备，可作为在线式潮位记录仪持续记录潮汐水深压力与水体温度。设备支持外接 5~30V DC 太阳能供电系统与内部 3.6V 电池双供电模式，保证站点长期稳定运行；采集数据通过 4G 网络实时传输到云端平台，适配地表水、地下水及海洋环境的远程水位水温监测场景。

K05 采用高稳定性液位测量传感元件，测量精度最高可达 ±0.05% FS，温度分辨率 0.05℃；内部循环存储容量＞3 万条（水位+水温+电池电压+时间戳），休眠电流＜5μA；搭载标准 RS485 Modbus-RTU 协议，可无缝对接 DCS 或 PLC 系统；配备电源反接保护与 2kV 浪涌电压保护，全 316L 不锈钢（或钛合金）密封壳体，IP68 全防水防护等级，可长期部署于海水与腐蚀性水体。

配套海洋环境数据采集主机，集成 4G 无线通讯、GPS 定位、自动唤醒与电源管理功能，预留 4 路 RS485 接口、2 路 4-20mA 接口，可接入其它传感器组网；同时具备移位报警、开舱报警、进水报警、防雷保护、授时功能，并预留铱星或北斗通讯接口，适配海洋无人值守遥测站部署需求。

## 规格参数

| 参数类别 | 指标 |
|----------|------|
| **压力测量** | 量程 0-50m / 0-200m（可选），精度 ±0.05% FS（0~50℃补偿范围内），超补偿范围 ±0.1% FS；分辨率 0.005% FS |
| **温度测量** | 量程 -20℃ ~ +80℃，精度 ±0.2℃，分辨率 0.05℃ |
| **存储性能** | 记录频率 1~5760 分钟可调，内存容量＞30000 条（水位+水温+电压+时间），实时时钟精度＜±5 min/year |
| **双供电系统** | 外接电源 5~30V DC；内部 3.6V DC 电池；电池寿命 10 年（60 分钟/次记录） |
| **输出接口** | RS485，标准 Modbus-RTU 协议；传输距离 ≤1km；2kV 浪涌保护；电源反接保护 |
| **采集主机选配** | 休眠电流 5μA，自动唤醒，4G 通信，GPS 定位；4 路 RS485 + 2 路 4-20mA；移位/开舱/进水报警；防雷+授时；预留铱星/北斗接口；IP68 |
| **太阳能供电选配** | 60W 太阳能板，24Ah 电池组，12V 系统 |
| **工作/贮存温度** | 工作 -10℃ ~ +80℃；贮存 -20℃ ~ +85℃ |
| **机械特性** | 接液材质 316L 不锈钢，外壳 316L 不锈钢（可选钛合金）；密封圈氟橡胶；电缆 PVC/聚氨酯 |

| **重量** | 约 300g（不含电缆） |
