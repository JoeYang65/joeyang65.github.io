# MOJOY LINK 项目专属知识库

> 本目录是项目长期维护的知识积累，AI 每次操作后需同步更新对应文件。

## 知识库文件索引

| 文件 | 用途 | 更新时机 |
|------|------|----------|
| [product-catalog.md](product-catalog.md) | 产品目录索引（型号、路径、标签、状态） | 新增/删除/修改产品时 |
| [tags-library.md](tags-library.md) | 标签库（用户独家维护的权威列表） | 用户同意新增标签时 |
| [seo-keyword-bank.md](seo-keyword-bank.md) | SEO 关键词积累库（按产品分类） | 新增产品或优化 SEO 时 |
| [site-changelog.md](site-changelog.md) | 站点变更记录（按日期记录每次上线内容） | 每次内容上线后 |

## 维护规则

1. **及时更新**：每次官网内容变更后，AI 必须同步更新相关知识库文件
2. **准确性**：数据必须与实际 `content/` 目录保持一致
3. **可追溯**：变更记录必须包含日期、操作内容、操作者（AI/用户）
4. **只追加不删除**：历史记录不覆盖，新记录追加到末尾
