# MOJOY LINK 官网 — 用户操作手册

> 本手册面向官网维护人员（您），说明如何与 AI 协作完成官网内容的更新维护。

---

## 一、快速开始

### 我要新增一个产品

1. 准备好产品资料（任意格式：PDF、Word、参数截图、文字描述均可）
2. 将资料发给 AI，或放入 `_ai-memory/inbox/` 目录后告知 AI
3. AI 会阅读分析资料，输出 5 类交付物：
   - ① 元数据提案（请确认 title/description/keywords/tags）
   - ② 页面正文（请审阅内容是否准确）
   - ③ SEO 优化说明（了解关键词策略）
   - ④ 宣传推广建议（可用于其他渠道宣传）
   - ⑤ 待办清单（补充图片等）
4. 逐项确认或提出修改意见
5. AI 创建页面文件，启动本地预览
6. 浏览器预览确认效果
7. 确认后，AI 提交 Git 并请求您确认推送
8. 您确认推送 → GitHub 自动构建 → 线上更新

### 我要修改现有内容

1. 告诉 AI 要修改哪个页面、修改什么
2. AI 定位文件，执行修改
3. 本地预览 → 确认 → 推送（同上）

### 我要更新图片

1. 将新图片发给 AI 或放入项目目录
2. AI 替换文件并预览
3. 如替换同名图片，AI 会提醒您可能需要清理 Cloudflare 缓存

## 二、您需要做的事

| 事项 | 说明 |
|------|------|
| 提供产品资料 | 型号、参数、功能描述、应用场景、图片 |
| 确认元数据 | AI 生成的 title/description/keywords/tags 是否准确 |
| 审阅正文 | 产品描述是否专业、参数是否正确 |
| 预览确认 | 浏览器查看本地预览效果 |
| 确认推送 | AI 提交 Git 后，您决定是否推送 |
| 线上验证 | 推送后访问官网确认效果 |
| 清理缓存 | 如图片未更新，按 AI 提示清理 Cloudflare 缓存 |
| 维护标签库 | 如需新增标签，在 `_ai-memory/knowledge/tags-library.md` 中添加 |

## 五、常见问题

### Q1：AI 说页面已创建，但线上看不到
**原因**：可能未推送或 GitHub Action 构建中。
**解决**：确认已完成 `git push`，然后在 GitHub 仓库的 Actions 页面查看构建状态。

### Q2：推送后图片没更新
**原因**：Cloudflare CDN 缓存。
**解决**：登录 Cloudflare → mojoylink.com → Caching → Configuration → Purge Everything，然后 `Ctrl+F5` 硬刷新。

### Q3：我想调整产品排序
**操作**：告诉 AI 要调整哪个产品，AI 修改 front matter 中的 `weight` 值（越小越靠前）。

### Q4：我想暂时隐藏某个产品
**操作**：告诉 AI，将产品页 `draft` 改为 `true`，推送后该页面不再显示。

### Q5：AI 提示需要新增标签
**操作**：查看 AI 的申请理由，如同意，在 `_ai-memory/knowledge/tags-library.md` 中添加新标签。

### Q6：本地预览地址是什么
**地址**：`http://localhost:1313/`，具体页面地址 AI 会告知。
